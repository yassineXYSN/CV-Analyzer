# Configuration N8N Workflow

## Webhook URLs
- Quiz Analysis: /analyze-quiz
- Interview Analysis: /analyze-interview

## Environment Variables
N8N_WEBHOOK_URL=https://your-n8n-instance.com/webhook

## Workflow Endpoints
1. Quiz Analysis Workflow
   - Endpoint: POST /analyze-quiz
   - Purpose: Analyze quiz results with AI
   - Input: Application data, job info, candidate profile, quiz data

2. Interview Analysis Workflow  
   - Endpoint: POST /analyze-interview
   - Purpose: Analyze interview results with AI
   - Input: Interview data, candidate responses, emotion analysis

## Usage
These workflows are used for AI-powered analysis of candidate assessments and interviews.
